# Methodology

1. Frame a question and inspect existing entities.
2. Catalogue sources without treating them as findings.
3. Extract bounded evidence or record observations with provenance.
4. Compare findings with claims; retain qualifications and contradictions.
5. Model workflows, decisions, interfaces and problems in context.
6. Form testable hypotheses and problem-led opportunities.
7. Run the smallest safe experiment that changes a decision.
8. feed learning back into entities, status, confidence and questions.

Changes should be reviewable in version control. Absence of evidence is recorded as uncertainty, not converted to a conclusion.
